# Operation: Blackout — תשתית מנוע המשחק

משחק רשת חינוכי מבוסס מכונת מצבים (Choose Your Own Adventure) לתרגול דקדוק באנגלית.
הגרסה הזו היא **תשתית מלאה ועובדת** עם 20 השלבים, עמודי שגיאה ועמוד ניצחון — מוכנה להחלפת התמונות והתוכן.

---

## למה Vanilla ולא Astro?

| שיקול | הבחירה שנעשתה |
| --- | --- |
| אפס שלב build | פותחים שרת סטטי ומריצים — אין `npm install`, אין קומפילציה, אין תלות בגרסת Node בבית הספר |
| אחסון | עובד כמו שהוא ב-GitHub Pages / Netlify / שרת בית ספרי / תיקייה ברשת |
| מבנה | הפרויקט מחולק למודולים (ES Modules) בדיוק כמו ב-Astro: נתונים, מנוע, תצוגה — כך שאפשר להעביר אותו ל-Astro בהמשך בלי לכתוב מחדש את הלוגיקה |
| משקל | ~40KB קוד, ללא frameworks, טעינה מיידית גם על טאבלט חלש |

אם בעתיד תרצה Astro (למשל לניהול תוכן ב-Markdown או ריבוי משחקים), כל מה שצריך להעביר הוא `js/engine.js` ו-`js/data/*.js` כמו שהם — הם לא נוגעים ב-DOM.

## הרצה

ES Modules לא נטענים מכתובת `file://`, ולכן צריך שרת סטטי קטן (לא build):

```bash
# אפשרות א' — Python (מותקן בכל מקום)
cd operation-blackout
python3 -m http.server 4321
# פתחו: http://localhost:4321

# אפשרות ב' — Node
npm start        # מריץ python3 -m http.server 4321
npm run dev      # חלופה: npx serve

# בדיקות לוגיקה (ללא דפדפן)
npm test
```

להעלאה לאינטרנט: כל אחסון סטטי (GitHub Pages, Netlify, Vercel, שרת בית ספרי). אין צורך ב-build.

## התמונות (assets)

הקוד טוען נתיבים יחסיים מתוך `assets/`, לפי המוסכמה שלך:

| קובץ | משמעות |
| --- | --- |
| `1.png` … `20.png` | תמונת השלב התקינה |
| `1false.png` … `20false.png` | תמונת השגיאה (Fallback) של אותו שלב |
| `victory.png` | תמונת הניצחון |

הכי פשוט: להעתיק את הקבצים שלך מעל ה-placeholders באותם שמות. אם קובץ חסר — לא נשבר עיצוב: מוצג placeholder נקי עם שם הקובץ החסר (כדי שיהיה ברור מה לתקן).

יחס תמונה מומלץ: 16:9 או 16:10, רוחב 1280px ומעלה. התמונות נחתכות אוטומטית (`object-fit: cover`), כך שאין עיוות.

## מבנה נתוני שלב (`js/data/stages.js`)

```js
{
  id: 1,                       // מספר השלב
  title: 'שער הכניסה',         // כותרת בעברית
  topic: 'Prepositions of Place',
  image: '1.png',              // relativ ל-assets/
  story: 'You are standing …', // הסיפור באנגלית
  prompt: 'Choose the correct word …',
  answers: [                   // 4 תשובות, בדיוק אחת correct: true
    { text: 'above',   correct: false },
    { text: 'under',   correct: true  },
    { text: 'between', correct: false },
    { text: 'inside',  correct: false },
  ],
  fallback: {
    image: '1false.png',
    message: '-5 Points! You looked in the wrong place …',
    ruleLabel: 'כלל דקדוקי',   // "כלל אוצר מילים" / "הסבר הבנת הנקרא"
    explanation: 'המילה Under משמעותה "מתחת" …',
  },
}
```

להוספת שלב: מוסיפים אובייקט למערך (והופכים את `id` לרציף). המנוע, ה-HUD, המספור וה"שלב X מתוך Y" מתעדכנים לבד.

## חוקי המשחק (מכונת המצבים)

```
STAGE ──תשובה נכונה (+10 ניקוד)──────────────► STAGE הבא
  │                                                 │
  │                                          אחרי שלב 20
  │                                                 ▼
  └──תשובה שגויה (−5 HP, −5 ניקוד)──► FALLBACK ──► VICTORY
                                          │
                              "הבנתי – חזור לשלב" ──► אותו STAGE
```

- **HP:** מתחיל ב-100, יורד ב-5 על כל טעות. הפס העליון משתנה לצהוב מתחת ל-40 ולאדום מהבהב מתחת ל-20.
- **ניקוד:** מתחיל ב-100, +10 לכל תשובה נכונה (מקסימום 300), −5 לכל טעות.
- **דירוגים** (לפי `game-config.js`): 280–300 Master Cyber Agent, 240–275 Senior Field Agent, 200–235 Junior Agent, ומתחת ל-200 "Agent in Training".
- תשובה נכונה מעבירה מיד לשלב הבא, בלי מסך ביניים. תשובה שגויה מציגה את תמונת ה-Fallback, המשוב, ההסבר בעברית וכפתור חזרה לאותו שלב — בלי לאפס את מה שכבר הושג.

כל החוקים מרוכזים באובייקט `RULES` ב-`js/data/game-config.js` — אפשר לשנות ערכים (למשל `hpPenaltyPerMistake: 10`) בלי לגעת בקוד.

> שים לב: לפי המפרט, HP הוא מד ויזואלי של "כמה נפגעת"; ירידת HP לא מסיימת את המשחק, והשחקן תמיד משלים את 20 השלבים. אם תרצה מצב "HP=0 ⇒ כישלון", זו תוספת של כמה שורות ב-`engine.js`.

## נגישות ומובייל

- פריסה מותאמת ל-3 נקודות שבירה: מובייל (עמודה אחת, כפתורים גדולים), טאבלט, דסקטופ (תמונה וטקסט זו לצד זו).
- ניווט מקלדת: `1`–`4` לבחירת תשובה, `Enter` לחזרה משלב השגיאה, `Enter` למשימה חדשה בניצחון.
- `aria-live` מכריז על כל שלב/טעות לקוראי מסך; כפתורים עם `aria-label`; `:focus-visible` ברור.
- כיבוד `prefers-reduced-motion`: מבטל אנימציות ומעברים למי שביקש.

## מה הלאה (אופציונלי)

1. **שמירת התקדמות** ב-`localStorage` (אפשר להוסיף `engine.serialize()` / `restore()`).
2. **מסך פתיחה** עם שם סוכן והסבר קצר לפני שלב 1.
3. **רמז** לכל שלב (כפתור "רמז" שמנכה 2 נקודות).
4. **דוח מורה**: ייצוא `engine.log` (איזה שלב, איזו תשובה, נכון/שגוי) ל-CSV.
5. **צליל** קצר להצלחה/שגיאה (Web Audio API, בלי קבצי מדיה).
